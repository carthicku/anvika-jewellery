# API Contract

* Base path: `/api/v1`. Interactive docs (development only): `http://localhost:8010/api/docs`.
* The machine-readable contract is `backend/openapi.json`. Regenerate it with
  `python -m app.cli export-openapi`, then run `npm run gen:api` in `frontend/` to refresh the
  TypeScript types. **This table is a guide; `openapi.json` is authoritative.**

## Conventions

### Requests
* JSON bodies (`Content-Type: application/json`), except image uploads (`multipart/form-data`).
* Cookies carry authentication (`access_token`, `refresh_token`) and the guest cart (`cart_token`).
* Every `POST/PUT/PATCH/DELETE` must send `X-CSRF-Token` equal to the `csrf_token` cookie
  (exempt: `/api/v1/webhooks/*`). Call `GET /api/v1/auth/csrf` once to obtain the cookie.
* Order creation requires an `Idempotency-Key` header (UUID generated by the browser once per
  checkout attempt). Repeating the request with the same key returns the same order.
* Request bodies are limited to 1 MB (10 MB for image uploads).

### Responses
* Money is serialised as a **string** with 2 decimal places (`"125430.00"`) to avoid floating-point
  loss in JavaScript. The frontend formats strings; it never does arithmetic with them.
* Timestamps are ISO-8601 UTC (`2026-10-14T09:30:00Z`).
* Lists are paginated:
  ```json
  { "items": [...], "page": 1, "page_size": 24, "total": 137, "pages": 6 }
  ```
  `page_size` max 100 (admin) / 48 (storefront).

### Errors — one format everywhere
```json
{
  "error": {
    "code": "PRICE_CHANGED",
    "message": "Some prices have changed. Please review your cart.",
    "details": { "...": "optional machine-readable context" },
    "request_id": "6f1c..."
  }
}
```
| HTTP | Typical `code` values |
|------|----------------------|
| 400 | `BAD_REQUEST`, `CSRF_FAILED` |
| 401 | `NOT_AUTHENTICATED`, `INVALID_CREDENTIALS`, `SESSION_EXPIRED` |
| 403 | `FORBIDDEN` |
| 404 | `NOT_FOUND` (also used when a resource exists but belongs to someone else) |
| 409 | `CONFLICT`, `OUT_OF_STOCK`, `PRICE_CHANGED`, `INVALID_STATE_TRANSITION`, `IDEMPOTENCY_CONFLICT` |
| 413 | `PAYLOAD_TOO_LARGE` |
| 422 | `VALIDATION_ERROR` (with `details.fields` → per-field messages) |
| 429 | `RATE_LIMITED` (with `Retry-After` header) |
| 500 | `INTERNAL_ERROR` (no stack trace; log correlated by `request_id`) |
| 502/503 | `PAYMENT_PROVIDER_ERROR`, `SERVICE_UNAVAILABLE` |

## Endpoints

Legend: 🌐 public · 👤 signed-in customer · 🔑 staff/admin (permission in brackets) · 🔒 signature-authenticated

### Auth — `/auth`
| Method | Path | Access | Purpose |
|--------|------|--------|---------|
| GET | `/auth/csrf` | 🌐 | Issue the `csrf_token` cookie |
| POST | `/auth/register` | 🌐 (rate-limited) | Create a customer account, start a session |
| POST | `/auth/login` | 🌐 (rate-limited) | Sign in; sets cookies |
| POST | `/auth/refresh` | 🌐 (refresh cookie) | Rotate tokens |
| POST | `/auth/logout` | 👤 | Revoke current session |
| POST | `/auth/logout-all` | 👤 | Revoke all sessions |
| GET | `/auth/me` | 🌐 | Current user or `null` |
| POST | `/auth/verify-email` | 🌐 | Consume an email-verification token |
| POST | `/auth/resend-verification` | 👤 (rate-limited) | Send a new verification email |
| POST | `/auth/forgot-password` | 🌐 (rate-limited) | Always returns 202 (no account enumeration) |
| POST | `/auth/reset-password` | 🌐 (rate-limited) | Consume reset token, set new password, revoke sessions |
| POST | `/auth/change-password` | 👤 | Requires current password; revokes other sessions |
| GET | `/auth/sessions` | 👤 | List active sessions |
| DELETE | `/auth/sessions/{id}` | 👤 | Revoke one own session |

### Account — `/me`
| GET/PATCH | `/me/profile` | 👤 | Name, phone |
| GET/POST | `/me/addresses` | 👤 | List / create |
| PATCH/DELETE | `/me/addresses/{id}` | 👤 (owner) | Update / delete |

### Catalogue
| GET | `/home` | 🌐 | Homepage data: featured categories, new arrivals, bestsellers, featured collections |
| GET | `/categories`, `/categories/{slug}` | 🌐 | Category tree / detail |
| GET | `/collections`, `/collections/{slug}` | 🌐 | Collections |
| GET | `/products` | 🌐 | Filters: `q`, `category`, `collection`, `purity` (multi), `metal_colour`, `min_price`, `max_price`, `in_stock`, `attr.<key>`; `sort` ∈ {relevance, newest, price_asc, price_desc}; `page`, `page_size` |
| GET | `/products/facets` | 🌐 | Available filter values + counts for the same filters |
| GET | `/products/{slug}` | 🌐 | Full detail incl. variants, stock status, price breakdown per variant |
| GET | `/products/{slug}/related` | 🌐 | Related products |
| GET | `/search/suggest?q=` | 🌐 | Up to 8 suggestions (products + categories) |
| GET | `/products/{slug}/reviews` | 🌐 | Approved reviews |
| POST | `/products/{slug}/reviews` | 👤 | Verified purchasers only; goes to moderation |

### Shipping
| GET | `/shipping/pincode/{pincode}` | 🌐 (rate-limited) | Serviceability, methods, estimated delivery range |

### Cart — `/cart` (guest cookie or signed-in)
| GET | `/cart` | 🌐 | Cart with backend-calculated totals, per-line `price_changed` / `stock_issue` flags |
| POST | `/cart/items` | 🌐 | `{variant_id, quantity}` |
| PATCH | `/cart/items/{id}` | 🌐 (own cart) | `{quantity}` |
| DELETE | `/cart/items/{id}` | 🌐 (own cart) | Remove line |
| POST | `/cart/coupon` / DELETE `/cart/coupon` | 🌐 | Apply / remove coupon |
| POST | `/cart/accept-prices` | 🌐 | Customer accepts current prices |

### Wishlist — `/wishlist`
| GET | `/wishlist` | 👤 | Items with current price/availability |
| PUT | `/wishlist/{product_id}` / DELETE | 👤 | Add / remove |
| POST | `/wishlist/merge` | 👤 | Merge guest (browser) wishlist slugs |

### Checkout & payments
| POST | `/checkout/quote` | 🌐 | Address PIN, shipping method → full breakdown (no side effects) |
| POST | `/checkout/orders` | 🌐 (`Idempotency-Key`) | Validates cart + `expected_total`, reserves stock, creates pending order and provider order; returns order reference, guest access token (guests), and checkout data |
| POST | `/payments/verify` | 🌐 (order access) | Verifies checkout signature + fetches payment → marks paid |
| POST | `/payments/retry` | 🌐 (order access) | New provider order for a still-pending order |
| POST | `/payments/simulator/pay` | 🌐 **dev/test only** | Simulator "pop-up" result (success / failure) |
| POST | `/webhooks/razorpay` | 🔒 HMAC | Razorpay events (idempotent by event id) |

### Orders
| GET | `/orders` | 👤 | Own orders (paginated) |
| GET | `/orders/{reference}` | 👤 owner, or 🌐 with `X-Order-Access-Token` | Order detail + timeline |
| POST | `/orders/{reference}/cancel` | owner / guest token | Cancel when eligible |
| POST | `/orders/{reference}/returns` | 👤 owner | Return/exchange request when eligible |

### Content & engagement
| GET | `/settings/public` | 🌐 | Store name, announcement, contact placeholders, payment provider mode |
| GET | `/content/{slug}` | 🌐 | Editable page content |
| POST | `/contact` | 🌐 (rate-limited, honeypot) | Contact enquiry |
| POST | `/newsletter/subscribe`, `/newsletter/unsubscribe` | 🌐 (rate-limited) | Newsletter |
| GET | `/sitemap.xml` (served at site root) | 🌐 | Sitemap |

### Admin — `/admin/*` (every route requires a staff/admin session **and** the named permission)
| Area | Endpoints | Permission |
|------|-----------|------------|
| Dashboard | `GET /admin/dashboard?from&to` | `dashboard:view` |
| Products | CRUD `/admin/products`, `/admin/products/{id}/variants`, images upload/reorder/delete, `POST /admin/products/{id}/preview-price` | `catalogue:write` |
| Categories / collections | CRUD | `catalogue:write` |
| Inventory | `GET /admin/inventory`, `POST /admin/inventory/{variant_id}/adjust`, `GET /admin/inventory/movements` | `inventory:write` |
| Orders | list/filter, detail, `POST .../status`, `.../shipments`, `.../refunds`, `.../notes`, payment events | `orders:write` |
| Customers | list, detail (orders, addresses) | `customers:view` |
| Discounts / coupons | CRUD | `promotions:write` |
| Gold rates | `GET /admin/gold-rates`, `POST /admin/gold-rates/preview`, `POST /admin/gold-rates` | `pricing:write` |
| Shipping | methods + zones CRUD | `settings:write` |
| Content | pages CRUD | `content:write` |
| Reviews | list, approve/reject | `content:write` |
| Returns | list, decide, mark received/refunded | `orders:write` |
| Enquiries / newsletter | list, update status | `customers:view` |
| Settings | `GET/PATCH /admin/settings` | `settings:write` |
| Audit logs | `GET /admin/audit-logs` | `audit:view` |
| Users (staff) | list, change role, deactivate | `users:manage` (admin only) |
